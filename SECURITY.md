# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | Yes                |

## Reporting a Vulnerability

If you discover a security vulnerability in `git-stats-lite`, please report it responsibly.

Do not open a public issue on GitHub. Instead, please report security concerns via GitHub Private Vulnerability Reporting at:

https://github.com/YusufBeratZengin/git-stats-lite/security/advisories/new

Alternatively, you may contact the maintainer directly via GitHub at https://github.com/YusufBeratZengin.

Please include:

- A clear description of the vulnerability.
- Steps or a minimal test repository to reproduce the behavior.
- Potential impact and threat assessment.

You will receive an acknowledgment within 48 hours, followed by updates on the remediation timeline.
